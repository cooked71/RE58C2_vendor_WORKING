    except FileNotFoundError:

def clean_makefile(mk_file, duplicates):
    """Remove duplicate entries from the makefile"""
    try:
        with open(mk_file, 'r') as f:
            content = f.read()
        
        # Pattern to match file entries in the makefile
        pattern = r'^\s*([\w\/\.@\-\$\(\)]+):.*\\$'
        
        lines = content.split('\n')
        cleaned_lines = []
        skip_next = False

You're right! If the services are also defined in android.bp files, then they're being built from source and the PRODUCT_PACKAGES is just including them in the build. The actual conflict is that you have both:

Prebuilt versions (from vendor blobs) being copied via PRODUCT_COPY_FILES

Source-built versions (from android.bp) being included via PRODUCT_PACKAGES

The solution is to either:

Remove from PRODUCT_PACKAGES - Use only the prebuilt vendor versions

Remove from PRODUCT_COPY_FILES - Use only the source-built versions

Since you have android.bp files building these services from source, you should remove the duplicate entries from your PRODUCT_COPY_FILES section (the find-copy-subdir-files calls that are copying the prebuilt binaries).
